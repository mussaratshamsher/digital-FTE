# Professional Demo Script: Digital FTE Factory

## Phase 1: The Problem (Hook) - 1 Minute
"Modern businesses are drowning in CRM manual entry and disconnected workflows. Human employees spend 40% of their time on repetitive data tasks instead of high-value sales. We built the Digital FTE Factory to solve this."

## Phase 2: The Command Center (Next.js UI) - 2 Minutes
- **Dashboard Walkthrough:** Show the clean interface.
- **Agent Status:** Demonstrate how we monitor the Sales, PM, and Support agents.
- **Activity Feed:** Point out the real-time execution logs.

## Phase 3: The "Magic" Moment (Live Agent Execution) - 3 Minutes
1.  **Trigger:** Initiate a task (e.g., "Onboard new enterprise customer 'Acme Corp'").
2.  **Orchestration:** Show the Orchestrator splitting the task.
3.  **Agent Collaboration:** 
    *   Sales Agent identifies the lead.
    *   PM Agent creates the project timeline.
    *   Support Agent sets up the knowledge base.
4.  **Verification:** Show the database record being created and the logs confirming completion.

## Phase 4: Under the Hood (Clean Architecture) - 2 Minutes
- **FastAPI Core:** "Our backend uses a repository pattern, ensuring the logic is decoupled from the database."
- **Multi-Agent Intelligence:** "Powered by Gemini 1.5 Pro, our agents aren't just scripts; they are autonomous entities with specialized tools."
- **Scalability:** "Built with Docker and optimized for cloud serverless deployment."

## Phase 5: Closing - 1 Minute
"The Digital FTE Factory isn't just an app; it's a workforce multiplier. Thank you."
